How it maps to hardware

The simulator and Pico use the same timing

The browser changes a circle from dark to bright. CircuitPython changes a pin from False to True. Everything else—the message, lookup table, loops, and pauses—is the same idea.

  • ·LED on for one timing unit
  • —LED on for three timing units
  • A → RLED off for three timing units
